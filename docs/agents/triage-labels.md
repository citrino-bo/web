# Etiquetas de triage

Las skills hablan en términos de cinco roles canónicos de triage. Este archivo mapea esos roles a las etiquetas reales del tracker de este repo.

| Rol en mattpocock/skills | Etiqueta en nuestro tracker | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Falta que quien mantiene evalúe el issue |
| `needs-info` | `needs-info` | Esperando información de quien reportó |
| `ready-for-agent` | `ready-for-agent` | Especificado y listo para que lo tome un agente sin supervisión |
| `ready-for-human` | `ready-for-human` | Requiere implementación humana |
| `wontfix` | `wontfix` | No se va a accionar |

Cuando una skill nombra un rol (por ejemplo "aplicá la etiqueta de triage lista para agente"), usá la etiqueta de la segunda columna.

Para cambiar el vocabulario, editá la segunda columna; las skills leen este archivo y no crean etiquetas nuevas.
